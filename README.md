
# 📓 Note App
A simple note-taking app built with HTML, CSS, and JavaScript. Create, edit, and organize your notes with an integrated recycle bin that allows you to restore or permanently delete deleted notes.

## ✨ Features

<ul> 
   <li>📝 Create notes with a title and content</li>
  <li>✏️ Edit existing notes</li>
  <li>🗑️ Delete notes</li>
  <li>🔄 Switch between active notes and the recycle bin</li>
  <li>♻️ Restore deleted notes from the recycle bin</li>
  <li>❌ Permanently delete notes from the recycle bin</li>
  <li>💻 Built with HTML, CSS, and JavaScript</li>
</ul>

## 💡 Lessons Learned

This project helped me improve my understanding of working with arrays and JSON data in JavaScript. I learned how to iterate through arrays and objects to manage, display, and update notes dynamically.

Additionally, I learned how to create reusable HTML templates and populate them with dynamic data using variables. This allowed me to render multiple notes with the same template while accessing the correct note based on its index. The project also strengthened my understanding of writing modular, reusable code and building interactive user interfaces with HTML, CSS, and JavaScript.
